# MIM FX FF PANEL

Android gaming utility for memory information, launching Free Fire, practical performance guidance, and aim-training practice.

## Build APK
Open GitHub Actions and run **Build MIM FX FF Panel APK**, or push changes to the app files on main. Download the `MIM-FX-FF-PANEL-debug` artifact from the completed workflow.

## Scope
This app does not inject into, modify, or bypass Free Fire. Android's normal app sandbox does not permit forcibly clearing other apps' memory or altering their aiming/recoil/gameplay. It makes no anti-ban or headshot guarantee.
